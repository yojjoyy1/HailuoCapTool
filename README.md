# 🐚 海螺剪輯器

在瀏覽器裡執行的影片剪輯軟體，不需要安裝任何套件，也不用註冊帳號。所有剪輯、錄影、語音辨識都在你自己的電腦上處理，影片不會上傳到任何地方。

## 功能一覽

- **剪輯**：在任何位置分割、刪除、複製片段，拖曳調整長度與位置，主影片軌自動磁吸接合
- **素材管理**：內建動態影片、背景圖、貼圖、背景音樂與音效，也能匯入自己的影片、圖片、GIF、音樂
- **疊加畫面**：隨時在影片上加入短影片或圖片（子母畫面、貼圖），可調整位置、大小、旋轉、透明度、混合模式
- **文字與特效**：文字樣式範本、14 種文字動畫、16 種畫面特效、濾鏡、LUT 調色
- **聲音**：調整或移除影片原聲、人聲強化、替換背景音樂、淡入淡出
- **自動字幕**：自動辨識影片中的語音產生字幕（支援中文並轉為繁體），也能手動打點、貼上逐字稿、匯入匯出 SRT
- **螢幕錄影**：錄製整個螢幕、某個視窗或瀏覽器分頁，可調整截取範圍，錄完直接變成素材
- **外部載入**：字型、LUT、文字範本、特效素材，可從檔案或網址載入，重新整理後仍會保留
- **專案存檔**：把整個剪輯進度連同用到的素材存成一個專案檔，換電腦也能繼續編輯
- **匯出**：輸出 MP4 或 WebM 影片，畫面比例支援 16:9、9:16、1:1

## 系統需求

| 項目 | 需求 |
|---|---|
| 作業系統 | macOS 或 Windows |
| Node.js | 18 以上版本（[下載](https://nodejs.org)，選 LTS 版即可） |
| 瀏覽器 | 建議使用 **Chrome** 或 **Edge**；Firefox、Safari 可用但部分功能較慢或不支援 |

## 啟動方式

### Mac

1. 雙擊資料夾中的 **`啟動剪輯器.command`**
2. 瀏覽器會自動開啟 http://localhost:5173

第一次執行如果出現「無法打開，因為來自未識別的開發者」，請在檔案上按右鍵 →「打開」→ 再按一次「打開」。若提示沒有執行權限，打開「終端機」輸入以下指令後再試一次：

```bash
chmod +x ~/Desktop/海螺剪輯器/啟動剪輯器.command
```

### Windows

1. 雙擊資料夾中的 **`啟動剪輯器.bat`**
2. 瀏覽器會自動開啟 http://localhost:5173

如果出現「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。

### 手動啟動

```bash
cd 海螺剪輯器
node server.js
```

然後用瀏覽器開啟 http://localhost:5173。若要換連接埠：`PORT=8080 node server.js`。

> 使用期間請保持啟動視窗（終端機）開著，關掉它剪輯器就會停止。若顯示「剪輯器已經在執行中」，代表已經有一個在跑，直接開瀏覽器即可。

## 使用說明

### 基本剪輯

1. 把影片拖進左側「媒體」區，或點虛線框選擇檔案
2. 把素材拖到下方時間軸，或點素材上的「＋」加到播放頭位置
3. 移動播放頭到想剪的位置，按 **S** 分割，選取不要的片段按 **Delete** 刪除
4. 點選片段後，右側「屬性」面板可調整畫面、聲音、速度、濾鏡等設定

時間軸由上到下為：特效、文字、字幕、疊加畫面、主影片、背景音樂。同一時間重疊的片段會自動放到新的軌道。

### 聲音處理

- 選取影片片段，在屬性面板調整音量、淡入淡出，或勾選「人聲強化」
- 按時間軸上方的「🔇 移除原聲」可移除選取片段（或全部影片）的原聲，再從「音樂」分頁拖入新的背景音樂
- 每條軌道左側的 🔊 可整軌靜音

### 自動字幕

1. 切到右側「字幕打點」分頁
2. 選擇模型與語言，按「自動辨識」
3. 辨識完成後可直接修改文字與時間，或在預覽畫面確認位置與樣式

| 模型 | 說明 |
|---|---|
| Base | 推薦，速度與準確度平衡 |
| Tiny | 最快，但較不準 |
| Small | 最準，下載檔案較大 |

> 第一次使用需要連網下載辨識模型（數十到數百 MB），之後瀏覽器會快取，速度會快很多。支援 WebGPU 的瀏覽器可勾選「GPU 加速」。

**手動打點**：播放影片時按 **M** 在當下新增一句字幕的開頭，按 **N** 標記結尾。也可以先貼上整份逐字稿，再邊聽邊打點。

### 螢幕錄影

1. 按上方「🎥 錄製畫面」，或「媒體」分頁中的「🎥 錄製螢幕 / 視窗」
2. 選擇「整個螢幕」、「應用程式視窗」或「瀏覽器分頁」，在瀏覽器跳出的視窗中挑選來源
3. 拖曳紅框調整截取範圍，或直接輸入 X、Y、寬、高；可鎖定 16:9、9:16、1:1、4:3 比例
4. 按「● 開始錄製」，右下角的控制列可暫停、停止或放棄
5. 錄完後自動加入素材庫（可選擇同時放到時間軸）

> - Mac 上「系統聲音」只能錄到瀏覽器分頁的聲音，錄其他視窗或整個螢幕時請改用麥克風
> - Mac 第一次錄影需要到「系統設定 → 隱私權與安全性 → 螢幕錄製」允許瀏覽器
> - 錄整個螢幕時，右下角的控制列也會入鏡，可將截取範圍避開，或改用瀏覽器的「停止共用」結束

### 外部載入

直接把檔案拖進「媒體」區，剪輯器會依副檔名自動分類；也可以在各分頁按「＋ 匯入」。

| 類型 | 格式 | 載入後位置 |
|---|---|---|
| 影片、圖片、音樂 | mp4、mov、webm、mkv、png、jpg、gif、webp、mp3、wav、m4a… | 「媒體」分頁 |
| 字型 | ttf、otf、woff、woff2 | 「文字」分頁、字型選單 |
| 文字範本 | json | 「文字」分頁 →「我的範本」 |
| 特效素材 | 透明 PNG、GIF、WebP 動畫、影片 | 「特效」分頁 →「我的特效素材」 |
| LUT 調色 | cube | 「特效」分頁、屬性面板的 LUT 選單 |

- **從網址載入**：在「媒體」分頁的輸入框貼上檔案的直接連結（不支援 YouTube、IG 等網頁連結）
- **特效素材**：火花、光暈等黑底素材，可在屬性面板把「混合模式」設為「濾色」去除黑色背景
- **自訂文字範本**：調好文字樣式後按「💾 存成我的範本」，可在「我的範本」匯出成 json 分享給別人
- 匯入的項目會保存在瀏覽器中，重新整理後仍在；按卡片上的 ✕ 可刪除

### 專案存檔

- **儲存**：按「💾 儲存專案」，存成 `.hlproj` 專案檔
- **開啟**：按「📂 開啟專案」，或直接把 `.hlproj` 檔拖進剪輯器

專案檔包含時間軸內容、字幕、畫面比例、音量，以及用到的匯入素材、字型與 LUT，所以搬到另一台電腦也能完整開啟。內建素材不會打包，開啟時會自動對應。

> 目前沒有自動存檔，關閉頁面前請記得儲存。

### 匯出影片

按右上角「⬇ 匯出影片」，選擇格式（MP4 / WebM）、畫質與影格率。匯出會以即時播放的方式錄製，所以 1 分鐘的影片大約需要 1 分鐘，過程中請保持分頁在前景。

## 快捷鍵

| 按鍵 | 功能 |
|---|---|
| 空白鍵 | 播放 / 暫停 |
| S | 在播放頭位置分割 |
| Delete / Backspace | 刪除選取的片段 |
| Ctrl/⌘ + Z | 復原 |
| Ctrl/⌘ + Shift + Z、Ctrl/⌘ + Y | 重做 |
| Ctrl/⌘ + D | 複製片段 |
| ← / → | 逐格移動（按住 Shift 每次 1 秒） |
| Home / End | 跳到開頭 / 結尾 |
| M / N | 字幕打點：開始 / 結束 |
| Esc | 取消選取 |
| Ctrl/⌘ + 滾輪（時間軸上） | 縮放時間軸 |

在預覽畫面上可直接點選物件、拖曳移動位置，用滾輪縮放大小。

## 常見問題

**Q：重新整理後時間軸的內容不見了？**
時間軸內容不會自動保存，請用「💾 儲存專案」存檔。匯入的素材、字型、LUT、範本則會自動保留在瀏覽器中。

**Q：從網址載入失敗？**
請確認是檔案的直接連結（網址結尾通常是 .mp4、.png 等）。需要登入才能下載的檔案，請先下載到電腦再拖進來。

**Q：瀏覽器提示儲存空間不足？**
匯入的檔案存在瀏覽器裡，空間有限。這個項目仍可使用，只是重新整理後不會保留；可刪除不需要的素材，或改用專案檔保存。

**Q：自動字幕不準或時間有偏差？**
可改用 Small 模型提高準確度，並確認語言設定正確。背景音樂太大聲會影響辨識，可以先降低音樂音量再辨識。

**Q：換了瀏覽器之後素材都不見了？**
每個瀏覽器的儲存空間是分開的，`localhost` 和 `127.0.0.1` 也視為不同網站。請用專案檔在不同瀏覽器之間搬移。

## 專案結構

```
海螺剪輯器/
├── index.html          主頁面
├── server.js           本機伺服器（含網址下載代理）
├── 啟動剪輯器.command   Mac 啟動檔
├── 啟動剪輯器.bat       Windows 啟動檔
├── css/style.css       介面樣式
└── js/
    ├── main.js         初始化、快捷鍵、預覽畫面操作
    ├── state.js        專案狀態、軌道與片段操作、復原/重做
    ├── library.js      素材管理區
    ├── builtin.js      內建素材、文字範本、特效、濾鏡
    ├── timeline.js     時間軸
    ├── inspector.js    屬性面板
    ├── renderer.js     畫面合成
    ├── player.js       播放與聲音
    ├── subtitles.js    字幕打點與自動辨識
    ├── asr-worker.js   語音辨識（Whisper）
    ├── exporter.js     匯出影片
    ├── recorder.js     螢幕錄影
    ├── project.js      專案檔存取
    ├── imports.js      外部載入（字型、LUT、範本、網址）
    ├── lut.js          LUT 解析與套用
    └── storage.js      瀏覽器本機儲存
```

- [OpenCC](https://github.com/nk2028/opencc-js)：簡體轉繁體
